# 🧠 AI 心智 · 情绪与记忆（精简版）

`astrbot_plugin_ai_mind` ｜ 给 AstrBot 装上会演化的情绪、长期记忆与一张记忆图谱。

**版本**：v2.1 ｜ **适用**：AstrBot >=4.5,<5 ｜ **依赖**：无第三方库

> 作者：挽风随行+DSH(主代码编写)、冰与火之歌

许可证 [AGPL-3.0](LICENSE) ｜ 面板 4 个页签 ｜ 零第三方依赖，存储与检索全部用标准库。

---

## 包含 / 不包含

| ✅ 这一版有 | ❌ 这一版没有（已精简掉） |
| --- | --- |
| 情绪：PAD 三维模型、演化与衰减、情绪曲线 | 内置人格、表达基调、任何「怎么说话」的注入 |
| 长期记忆：攒批抽取、三路检索、隐私红线 | 人格预设 / 自定义人设文件 |
| 记忆图谱：节点-关系图、跟随会话、批量删除 | 提示词编辑（只用代码默认值） |
| 面板 4 页签、4 条指令、2 个 LLM 工具、备份与迁移 | 记忆垃圾桶、认人 / 好感度、面板主题切换 |

> 插件只负责「报心情」和「报记忆」；怎么说话，完全由你机器人自己的提示词决定。

## 功能

- 🎭 **情绪会自己演化**：PAD 三维模型随对话起伏，按半衰期自然衰减，没人理也会慢慢回落。
- 🧠 **长期记忆会自己攒**：攒够几轮或静默一段时间后交给模型抽取成条目，去重后入库。
- 🔍 **三路检索注入**：每轮按「常驻 + 最近 + 相关」挑出该记得的，贴在当前消息后注入。
- 🕸 **记忆图谱**：把记忆铺成节点-关系图，关键词当桥自动聚簇，跟着面板选中的会话走。
- 🛡 **隐私红线**：证件号、住址、密码等敏感信息只在本人私聊出现，绝不进群聊。
- 📊 **面板 4 页签**：情绪曲线、长期记忆、记忆图谱、通用配置，能看能改、可一键恢复默认。
- 📦 **零第三方依赖**：`requirements.txt` 为空，升级插件不会动你的数据。

## 情绪

- **PAD 三维**：愉悦（P）、唤醒（A）、掌控（D）各取 -1 ~ 1，描述「此刻」的情绪。
- **心境**：情绪的慢速平均，比情绪稳定得多；长时间没人说话会往「冷淡」方向滑。
- **衰减**：情绪与心境都按半衰期往气质基线回落，参数可在配置里调。
- **情绪强度**：独立可调、会自己衰减的 0~1 数值，支持指数 / 线性 / 不衰减三种策略。
- **一键改成**：23 种情绪原型（平静、开心、亲昵、委屈、吃醋……），点谁就是谁。
- **冻结**：聊天改不了、时间也不衰减，重启不解冻；解冻后只从那一刻开始衰减。
- **情绪曲线**：P/A/D 三条线 + 强度曲线 + 气质基线虚线，支持拖点改历史。
- **安全优先**：识别到自伤 / 轻生信号时短路处理，整段注入安全优先指令。

## 长期记忆

| 桶 | 作用 |
| --- | --- |
| **常驻** | 稳定事实：名字、生日、长期喜好，每轮都在 |
| **最近** | 最近几天发生的事，跨会话也还记得 |
| **相关** | 按词法相关度从旧记忆里捞；配了 Embedding 会叠加语义分 |

- **抽取**：攒够 N 轮或静默 M 分钟，交给模型抽成条目（事实 / 喜好 / 经历 / 约定 / 关系 / 其他）。
- **去重**：抽取参考只看当前会话能看见的记忆，入库再按同作用域比对一次。
- **手动维护**：面板里可搜索、添加、修改、删除、批量管理；手动添加会自动抽关键词，关键词会变成图谱上的浅色小点。

## 记忆图谱

- **联动会话**：只画当前选中会话的记忆，外加没绑会话的通用记忆。
- **4 类节点**：记忆（实心圆，越大越重要）、关键词（浅色小点）、人、会话。
- **聚簇**：关键词当桥做连通分量，高频词不当桥，免得整张图糊成一坨。
- **交互**：拖节点、滚轮缩放、悬停看提示、点节点看详情、手机双指捏合。
- **多选管理**：全选 / 清空 / 删除选中（连点两次才执行），可整簇选中。

## 安装

1. 把整个目录放进 `data/plugins/`（目录名建议改为 `astrbot_plugin_ai_mind`，与插件名一致）。
2. 在 AstrBot 插件管理里**重载插件**，或直接重启 AstrBot。
3. 确认配置好**默认对话模型**（记忆抽取要用它），然后正常聊天即可。
4. 面板入口：**WebUI › 插件 › AI 心智 · 情绪与记忆（精简版） › 页面**。

> **从旧版升级**：装好这个之后，把 `data/plugins/` 下的 `astrbot_plugin_ai_emotion`
> 和 `astrbot_plugin_ai_memory` 删掉（或停用），否则两套逻辑会同时注入，情绪会被算两遍。

## 配置

全部配置都在 AstrBot 配置页，也可以在面板「通用配置」页直接改，改完保存并热更新。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `emotion.persona.bot_name` | 空 | 她的名字 |
| `emotion.dynamics.emotion_half_life` | 240 | 情绪半衰期（秒） |
| `emotion.dynamics.mood_cold_after_minutes` | 360 | 在基线上平静多久没人理才变冷淡（分钟，`0` = 关） |
| `emotion.intensity.decay` | `exponential` | 强度衰减策略：`exponential` / `linear` / `off` |
| `memory.capture.batch_turns` | 6 | 攒够几轮对话抽取一次记忆 |
| `memory.extract.provider_id` | 空 | 用哪个模型抽取记忆（默认当前对话模型） |
| `memory.privacy.private_memory_in_group` | `false` | 群聊里是否也带上私聊记忆 |
| `memory.embedding.enabled` | `false` | 是否启用向量检索 |
| `commands.admin_only_mutations` | `true` | 改动类指令（重置 / 设定 / 清空）仅限管理员 |
| `advanced.cache_friendly` | `true` | 省 token：让前缀缓存稳定命中 |

> 想手调情绪基线：打开 `emotion.persona.custom_temperament`，再填三个 `temperament.*`（-1 ~ 1）。
> 说话方式不归插件管，完全由你机器人自己的提示词决定。

## 使用

### 指令

| 指令 | 别名 | 作用 |
| --- | --- | --- |
| `/情绪` | `/心情` | `帮助` `历史` `详细` `冻结` `解冻` `重置` `设定 P A D` `强度 0~1` |
| `/记忆` | `/回忆` | `搜索 <词>` `记住 <内容>` `忘记 <编号>` `清空 [全部]` |
| `/隐私` | — | 看自己在插件里留下了什么；管理员可管拒绝名单 |
| `/忘我` | `/删除我的数据` | 删掉你自己的全部数据 |

> 总开关 `commands.enabled`；改动类操作受 `commands.admin_only_mutations` 限制为管理员。

### LLM 工具

| 工具 | 作用 |
| --- | --- |
| `recall_long_term_memory` | 想不起对方说过什么时主动回忆 |
| `memorize_long_term_memory` | 把值得长期记住的信息记下来 |

### 面板 4 页签

| 页签 | 能做什么 |
| --- | --- |
| 情绪曲线 | 看此刻心情与曲线，操纵 / 冻结 / 一键改成，下方是维护与备份卡片 |
| 长期记忆 | 搜索、筛选、分页、批量管理与手动添加 |
| 记忆图谱 | 可视化关系图，多选批量删除 |
| 通用配置 | 在面板里改配置并保存，可一键恢复默认 |

## 数据与备份

数据都在 `data/plugin_data/astrbot_plugin_ai_mind/`：

| 文件 | 内容 |
| --- | --- |
| `mind.db` | 记忆、情绪曲线采样点、词表命中记录 |
| `emotion_state.json` | 情绪状态快照（含冻结名单，自带备份） |
| `pending_turns.json` | 还没抽取的对话，防重启丢 |
| `debug_sessions.json` | 调试模式开关的会话 |
| `privacy_overrides.json` | 面板上改的隐私设置 |

- **备份**：AstrBot 停下来后，把整个数据目录复制一份最稳妥；升级插件不会覆盖数据。
- **迁移用面板「备份与迁移」卡**：把全部配置与全部记忆打成一个 JSON，可导出、下载、粘贴或从服务器文件导入；导入后逐项核对，重复导入幂等。
- 备份**不含向量**（到新机器按自己的模型重算），也**不含情绪状态与曲线**（要一起搬就复制整个数据目录）。

## 隐私与合规

- **敏感信息默认拒绝**：证件号、手机号、银行卡、住址、学校、密码等命中后，永久限定为「只在私聊里、只对本人」，**绝不进群聊**。
- **群里学到的**默认只在该群可用，不跨群（`memory.privacy.group_scope`，默认 `session`）。
- **拒绝名单**：名单里的人既不采集也不注入，支持 `平台:uid` 写法。
- **`/忘我`**：一键删掉自己的记忆、关系与情绪命中记录（立即真删）。
- **档案导出**：管理员可以把某个人的数据导出成 JSON。

---

## 注意事项

- 插件**不注入人格、表达基调**，只管「此刻什么心情」「记得什么」；语气听人设的。
- 三块提示词**只用代码默认值**，没有编辑入口；插件也不处理、不屏蔽其它插件的注入。
- 敏感信息红线是**硬性**的：命中即限定私聊，不要指望在群里看到这类记忆。
- 面板为**固定暗色**、零构建；手机端支持双指缩放；曲线数据会随使用增长，可在面板压缩曲线、整理数据库。
- 记得定期备份数据目录；换机器或重装前先导出备份。
